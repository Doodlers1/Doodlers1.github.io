LiveBot privacy policy

Last updated: November 23, 2026.

What LiveBot accesses

LiveBot asks Google only for the "drive.file" permission. With it, LiveBot can see and change only the files it creates itself. It creates one file, "LiveBot feed.json", in the signed-in user's own Google Drive. It cannot see any other file in that Drive.

What it stores and where

The Google sign-in is kept only on the owner's own computer. LiveBot does not run any server, does not collect data from anyone, and does not share, sell or send data to anyone else. The status file stays in the owner's own Google Drive.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting "LiveBot feed.json" from Google Drive removes everything LiveBot wrote.

Contact

Questions: use the support email shown on LiveBot's Google sign-in screen.
